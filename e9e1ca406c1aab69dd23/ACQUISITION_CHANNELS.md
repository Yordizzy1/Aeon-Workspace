# Customer acquisition channels

The product now has automated first-party discovery and measurement. These additional channels are **one-time distribution actions**, not recurring fulfillment.

## Already automated

- Public Render landing page with conversion copy and tracked checkout links.
- `robots.txt` + `sitemap.xml`.
- OpenAPI 3.1.
- `llms.txt`, `agents.txt`, `agents.json`, and `/.well-known/api-catalog`.
- IndexNow submission while AEON is running locally.
- GitHub README backlinks.
- Privacy-preserving source/click/paid funnel telemetry in the AEON UI.
